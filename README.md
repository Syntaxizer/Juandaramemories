# Juan & Dara

A delicate, responsive photo-story website made from the photographs in `X.zip`.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example `juan-and-dara`).
2. Upload **everything inside this folder** to the repository. `index.html` must be in the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then save.
6. GitHub will give you a public `github.io` address. It can be opened directly on your phone.

The site is plain HTML/CSS/JavaScript, so there is no build step, Node.js, or framework required.
